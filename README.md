## ✨ الميزات

### 🔑 توليد أكواد الاشتراك
- توليد كود صالح **لجهاز واحد فقط** (مرتبط ببصمة الجهاز)
- اختيار مدة جاهزة: 7 / 30 / 90 / 180 / 365 يوم
- أو إدخال عدد أيام مخصص
- تاريخ بداية اختياري (افتراضي = اليوم)
- نسخ الكود بضغطة واحدة

### 🔍 التحقق من الأكواد
- لصق أي كود والتحقق من صحته فوراً
- عرض: المدة، تاريخ الانتهاء، الحالة (ساري/منتهي)، بصمة الجهاز

### 📱 معلومات الجهاز الحالي
- قراءة بصمة هذا الجهاز تلقائياً (نفس بصمة تطبيق تاجر برو على نفس الهاتف)
- نسخ البصمة للاختبار السريع
- ملاحظة: البصمة محسوبة بنفس خوارزمية تطبيق تاجر برو (salt = `com.tajirpro.app`)

### 📜 سجل الأكواد المُولّدة
- حفظ تلقائي لكل كود يتم توليده
- عرض الحالة (ساري/منتهي) لكل كود
- نسخ أي كود من السجل
- تصدير السجل: CSV (يدعم العربية) أو JSON

### 🎨 واجهة عربية RTL
- وضع ليلي/نهاري مع حفظ التفضيل
- تصميم عصري أنيق مطابق لهوية تاجر برو
- يعمل بالكامل بدون إنترنت

## 🔐 صيغة كود الاشتراك

```
TJP-{مدة_بالأيام}-{بصمة_الجهاز_8حروف}-{تاريخ_الانتهاء_base36}-{تحقق_2حروف}
مثال: TJP-365-A1B2C3D4-G2B-B4
```

| الحقل | الوصف |
|-------|-------|
| مدة | عدد أيام الاشتراك (30، 90، 365…) |
| بصمة الجهاز | 8 محارف سداسية عشر — تُعرض داخل تطبيق تاجر برو |
| تاريخ الانتهاء | عدد الأيام منذ 1970-01-01 بترميز base36 |
| تحقق | حرفان من مجموع تحقق متعدد الحدود |

## 📋 طريقة الاستخدام

1. افتح تطبيق «تاجر برو» على هاتف التاجر
2. اذهب إلى: الإعدادات ← الاشتراك ← معلومات الجهاز
3. انسخ «بصمة الجهاز» (8 محارف)
4. أرسل البصمة للمسؤول (صاحب هذا التطبيق)
5. هنا في «مولّد المفاتيح»: أدخل البصمة + اختر المدة + اضغط «توليد الكود»
6. انسخ الكود المُولّد وأرسله للتاجر
7. يُدخل التاجر الكود في تطبيق تاجر برو لتفعيل الاشتراك

- كل كود مرتبط ببصمة الجهاز ولا يعمل على أي جهاز آخر
- التحقق يتم محلياً بدون إنترنت
